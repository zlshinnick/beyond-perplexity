# Beyond Perplexity

Temporary **Coming soon** page for *Lasting Effects of Abstract Pretraining Beyond Perplexity*.

Live: https://zlshinnick.github.io/beyond-perplexity/

The page matches the [Procedural Core coming-soon page](https://zlshinnick.github.io/procedural-core/): a compact header, centered project mark and status badge, Source Serif 4 heading, Inter body text, and a white-to-soft-gray background. Beyond Perplexity retains its warm orange accent, connected-node mark, authors, and affiliation logos. Logos form a single row on desktop and a two-column grid on mobile.

## Local preview

```sh
python3 -m http.server 4173
```

No build step or JavaScript is needed. GitHub Pages serves the root of `main`.

## Full research page

The complete research site is preserved on the **`research-page` branch**, starting at commit `84772ba`. It includes the results explorers, stack/queue demonstration, figures, data, paper PDF, and provenance notes. The temporary deployment contains only the landing page and its branding assets. Restore or adapt the preserved page when ready to launch.
